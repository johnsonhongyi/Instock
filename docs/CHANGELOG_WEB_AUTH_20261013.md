### 访问规则与认证保护

- `johnsonhongyi.asuscomm.com` 域名始终要求登录；默认私有网段直接访问免登录。
- 用户管理和密码修改始终要求登录，内网免登录不授予账号管理权限。
- 现场外网 `39988` 端口映射将来源转换为 `192.168.50.1`。该网关默认排除免登录资格，解决修改 Host 即可绕过认证的问题。
- 未配置代理携带转发头时要求登录；只有明确配置的可信代理可以参与真实来源解析。
- 页面未登录跳转 `/login`，数据/执行 API 未登录返回 HTTP 401；认证相关响应禁止缓存。
- 密码采用带随机盐的 PBKDF2-SHA256 哈希，计算次数为 600,000；真实初始密码不写入源码或版本说明。
- 使用 HttpOnly、SameSite=Lax 签名会话，有效期一天。签名密钥随机生成并持久化，替换原有固定密钥。
- 修改密码时递增会话版本，使该用户全部旧会话失效；账号表单校验 CSRF，现有业务写接口拒绝跨源浏览器请求。
- 登录失败按连接来源限流；Linux 新建账号目录权限为 700，数据库权限为 600。

### 用户管理

- 首次初始化管理员 `johnson`；已有账号数据不会因服务重启恢复为初始密码。
- 管理员可以添加普通用户或管理员，并重置其他用户密码。
- 所有已登录用户可以使用原密码修改自己的密码、退出登录；普通用户不能添加用户或修改其他账号密码。
- 密码长度要求为 8–256 位；账号库位于现有 cache 挂载内，默认路径为 `instock/cache/auth/users.sqlite3`。
